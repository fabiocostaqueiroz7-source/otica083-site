PROJETO DEFINITIVO - ÓTICA 083

Este projeto tem:
- Landing page premium
- Catálogo dinâmico
- Painel admin em admin.html
- Login de administrador
- Cadastro de armações
- Upload de fotos
- Busca e filtro por categoria
- Integração preparada para Supabase
- Publicação no Netlify

ARQUIVOS:
index.html      = site
admin.html      = painel administrativo
style.css       = visual
script.js       = catálogo público
admin.js        = painel admin
config.js       = onde você cola as chaves do Supabase
supabase.sql    = código para criar a tabela no Supabase

PARA FINALIZAR:
1. Enviar arquivos para GitHub.
2. Conectar GitHub ao Netlify.
3. Criar conta no Supabase.
4. Executar o arquivo supabase.sql no SQL Editor.
5. Criar bucket público chamado produtos.
6. Criar usuário admin no Supabase Authentication.
7. Copiar URL e ANON KEY do Supabase.
8. Colar no config.js.
9. Enviar config.js atualizado ao GitHub.
10. Acessar seu-site.netlify.app/admin.html.
